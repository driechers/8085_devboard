# 8085 Demo Board

This is fun project of mine because I found several retro pc components and wanted to use them. I put together a breadboard test of an 8085, tested some 6116s and some 2816s and with an 8282, 4011 and voltage regulator, button, and passive components i had laying around put together this board. I got some simple asm programs running on it and attempted to get basic1k working gave up after a while and got tinybasic working isntead although it was a lot of work too. All the software is built with ASL as it seems to be the best assembler out there for retro chips.

I owe most credit to this guy! https://tomnisbet.github.io/Simple8085/docs/build
